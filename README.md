## 安装方式

RunCat 365 可通过 Microsoft Store 安装。

- 系统要求：Windows 10 版本 19041.0 或更高
- Microsoft Store：https://apps.microsoft.com/detail/9nw5lpnvwfwj
- 支持语言：
  - 简体中文
  - 繁体中文
  - 英文（默认）
  - 法语
  - 德语
  - 日语
  - 西班牙语

## 功能特性

- 🐱 **可爱的动画角色** - 猫咪、鹦鹉、小马等多种角色可选
- 📊 **实时系统监控** - CPU、GPU、内存、磁盘、网络使用率
- 🎨 **主题支持** - 跟随系统、浅色、深色模式
- 🎮 **内置小游戏** - 奔跑猫咪无尽跑酷游戏
- 🌐 **多语言支持** - 7 种语言界面
- ⚡ **轻量高效** - 基于 .NET 10 构建，性能优异
